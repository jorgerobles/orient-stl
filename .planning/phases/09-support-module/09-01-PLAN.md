Create `crates/support/src/island.rs` implementing `detect_islands`:

Algorithm (per HANDOFF section 4.3):
1. Rasterize mesh at each layer height → binary grid
2. For each cured pixel in current layer, check if connected to cured pixel in layer above
3. If NOT connected → mark as island pixel
4. Connected components on island pixels → Islands

Implementation approach:
- Project triangle vertices onto 2D plane perpendicular to build direction
- Use a scanline rasterizer: for each triangle, fill the grid cells it covers at each z-slice
- Layer iteration: from z_min to z_max in layer_height steps
- Connected components: BFS/union-find on the grid

**volume.rs** — Volume-above heuristic:

```rust
pub fn compute_volume_above(
    positions: &[f32],
    normals: &[f32],
    areas: &[f32],
    point: &[f32; 2],  // 2D point on island
    direction: &[f32; 3],
) -> f32

pub fn classify_support_type(volume: f32, config: &SupportConfig) -> SupportType
```

Implementation:
- Cast ray upward from point along -direction
- For each intersected triangle: accumulate `area × distance_to_next_intersection`
- This gives the volume of material above the point
- Classification: `< light_threshold` → Light, `< medium_threshold` → Medium, else → Heavy

Use Möller-Trumbore ray-triangle intersection (implement directly, don't depend on orient crate).

**placement.rs** — Contact point placement:

```rust
pub fn place_contacts(
    island: &Island,
    positions: &[f32],
    normals: &[f32],
    direction: &[f32; 3],
    support_type: &SupportType,
    config: &SupportConfig,
) -> Vec<ContactPoint>
```

Implementation:
- Variable-density Poisson-disk sampling on island surface
- Spacing based on support type: Light 2.5-6mm, Medium 2-5mm, Heavy 1.5-3.5mm
- Edge/corner seeding: detect grid pixels at island boundary, add extra sample points there
- For each sample point, project back to 3D mesh surface (find nearest triangle, interpolate)

Circular deformity adjustment (HANDOFF section 4.4):
- Compute local curvature at each contact point
- `cos = dot(normal, -direction)`
- Bottom of cylinder (cos > 0.7) → upgrade to Heavy density
- Sides (0.3 < cos < 0.7) → Medium
- Top (cos < 0.3) → Light or skip

**raft.rs** — Line-connected raft generation:

```rust
pub fn generate_raft(
    contacts: &[ContactPoint],
    config: &SupportConfig,
) -> RaftGeometry
```

Implementation:
1. Collect all contact base points (2D projection onto raft plane)
2. Compute convex hull of base points (use existing geometry-kernel::flat functions if accessible, or implement simple gift-wrapping)
3. Delaunay triangulation of convex hull → raft mesh triangles
4. MST + extra edges → line connections (ensures all supports connected to raft)
5. Output: vertices (flat f32), triangle indices, line indices

For Delaunay: implement Bowyer-Watson algorithm (~150 lines). For MST: Kruskal's with union-find.

Tests:
- Two contacts → raft connects both
- Single contact → minimal raft (just the base)
- Three contacts in triangle → full triangular raft
